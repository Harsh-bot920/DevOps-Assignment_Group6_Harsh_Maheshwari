# Reference Videos & Learning Resources

The links below are official project resources selected for learning and reference. The project stores the resource URLs rather than copying video content.

| Topic | Resource | Purpose |
|---|---|---|
| Grafana fundamentals | https://grafana.com/tutorials/grafana-fundamentals/ | Beginner tutorial covering metrics, logs, dashboards, and alerts |
| Grafana official channel | https://www.youtube.com/@Grafana | Official tutorials, demos, talks, and observability videos |
| Log monitoring | https://grafana.com/resources/log-monitoring/ | Official log-monitoring resources and videos |
| Loki workshop | https://grafana.github.io/loki-workshop/lab1/explore-logs/ | Guided exercise for exploring and filtering logs |
| Prometheus overview | https://prometheus.io/docs/introduction/overview/ | Official Prometheus architecture and metric-monitoring overview |
| OpenTelemetry Logs | https://opentelemetry.io/docs/concepts/signals/logs/ | Official explanation of log records and the Logs API |

## Review Rule

Check links periodically. Prefer first-party project documentation or channels. Do not claim that a resource demonstrates the team's own runtime unless the team actually reproduced the steps.
