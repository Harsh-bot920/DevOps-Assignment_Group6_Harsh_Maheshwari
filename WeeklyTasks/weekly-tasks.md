# Member 05 — Weekly Tasks

## Week 01 — Log Foundations
- Study logs vs metrics vs traces.
- Identify application, system, access, and error logs.
- Learn severity levels.
- Write three structured log examples.

## Week 02 — Collection and Analysis
- Study log collection pipelines.
- Practice time-based filtering.
- Practice grouping by service and severity.
- Learn correlation IDs and trace IDs.

## Week 03 — Investigation and Security
- Work through the troubleshooting examples.
- Write a small incident runbook.
- Review examples for secret leakage.
- Define a basic retention/rotation policy.

## Week 04 — Resources and Integration
- Review official Prometheus, Grafana, Loki, and OpenTelemetry resources.
- Add real project screenshots only after the team runs the stack.
- Check links and filenames.
