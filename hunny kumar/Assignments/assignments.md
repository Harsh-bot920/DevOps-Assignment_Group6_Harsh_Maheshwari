# Member 05 — Log Monitoring Assignments

## Conceptual

1. Explain log monitoring and its role in DevOps.
2. Compare logs, metrics, and traces.
3. Explain application, system, access, error, and audit logs.
4. Explain the purpose of each common log level.
5. Explain structured logging and why it improves analysis.
6. Describe a centralized log-collection pipeline.

## Practical

7. Design a log-monitoring workflow from source to investigation.
8. Given a sequence of log lines, identify the earliest likely root-cause event.
9. Build a log-quality checklist for a sample application.
10. Create a runbook for investigating HTTP 500 errors.
11. Identify sensitive values that must be removed from sample logs.
12. Correlate a sample log incident with CPU, memory, and request-rate metrics.
