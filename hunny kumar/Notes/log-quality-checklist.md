# Log Quality Checklist

Before shipping a log statement, check:

- [ ] Timestamp is available
- [ ] Severity is appropriate
- [ ] Service/component is identifiable
- [ ] Message explains the event
- [ ] Operation/context is included
- [ ] Correlation ID is included when useful
- [ ] No credentials/secrets are present
- [ ] Repeated events will not create uncontrolled noise
- [ ] Fields use stable names
